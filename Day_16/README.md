# You are tasked to build a Course Enrollment Tracker where:

- You have a list of Courses.
- Each Course has a list of Students enrolled.
- Some students might be enrolled multiple times (simulate duplicates).

## Operations to Perform:

1. Maintain a List of Courses (ArrayList).
2. For each Course, maintain a List of Student Names (duplicates allowed).
3. Sort the Courses Alphabetically.
4. For a given Course, count how many times a Student is enrolled (frequency count).
5. Shuffle the Courses randomly.
6. Print a Formatted Report showing:
   - Course → List of Students.

## Expected Data Example:

- Courses:
  - ENG101: Alice, Bob, Alice
  - SCI201: Eve, Frank, Eve
  - COM301: Ivan, Judy
